🛡️ 1. Propósito y Arquitectura de las Herramientas

El conjunto de herramientas de auditoría de seguridad Linux está diseñado bajo los estrictos estándares de infraestructura empresarial (L3). Permite evaluar la postura de seguridad, cumplimiento de CIS Benchmarks, versionamiento de kernel y detección automática de roles de aplicación de manera no destructiva y modular.

audit_vulnerabilities.sh

Auditor local modular de un solo nodo. Ejecuta más de 20 controles de seguridad en 9 dominios y genera consola, reporte JSON y un Dashboard HTML autocontenido e interactivo para presentaciones ejecutivas.

audit_multiserver.sh

Orquestador multiserver basado en SSH. Despliega de forma desatendida y paralela el script de auditoría en flotas completas de servidores, recopilando y consolidando los reportes por host en una sola ejecución.

🔍 2. Módulos de Análisis Incluidos (9 Dominios)

1. AUTH: Identidad, cuentas UID 0, integridad de /etc/shadow y privilegios sudo NOPASSWD.
2. SSH: Hardening de acceso remoto (PermitRootLogin, PasswordAuthentication, MaxAuthTries).
3. NETWORK: Estado de Firewalls (firewalld/iptables), ip_forward, SYN cookies y sockets en escucha.
4. FS: Opciones de montaje en /dev/shm (nodev, nosuid, noexec), binarios SUID y sticky bit.
5. SERVICES: Detección de servicios heredados inseguros (Telnet, RSH, TFTP, vsftpd).
6. KERNEL: Protección de memoria con ASLR, suid_dumpable y restricción de dmesg.
7. MAC: Control de Acceso Mandatorio (SELinux / AppArmor) y trazabilidad con auditd.
8. UPDATES: Parches de seguridad pendientes universales (dnf/yum/apt/zypper) y necesidad de reboot por kernel.
9. WORKLOAD: Detección automática de roles del servidor (DB Server, Web Server, App Server).

🚀 3. Guía de Uso y Comandos de Ejecución

A. Auditoría Local con audit_vulnerabilities.sh

Ejecuta todos los módulos en el servidor local y genera los reportes para un cliente específico:

./scripts/bash/audit_vulnerabilities.sh --client "Banco Corporativo" --output-dir ./reports/banco_corp

Ejecución selectiva de módulos específicos (ej. Red y SSH):

./scripts/bash/audit_vulnerabilities.sh --modules network,ssh --client "Auditoría Parcial"

B. Orquestación Masiva con audit_multiserver.sh

Audita múltiples servidores en paralelo mediante SSH utilizando una lista de IPs:

./scripts/bash/audit_multiserver.sh --hosts "192.168.1.10,192.168.1.11,srv.empresa.com" --client "Flota Datacenter" --identity ~/.ssh/id_rsa --jobs 5

Auditoría leyendo servidores desde un archivo de inventario externo:

./scripts/bash/audit_multiserver.sh --hosts-file ./inventories/production/hosts.txt --user root --output-dir ./reports/produccion
